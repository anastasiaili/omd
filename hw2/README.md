# Домашнее задание 2

Программа обрабатывает данные о сотрудниках из файла `Corp_Summary.csv` и формирует три отчета

## Отчеты

1. Список департаментов и входящих в них отделов без повторений
2. Статистика по каждому департаменту (количество сотрудников, минимальный, максимальный и средний оклад)
3. Сохранение статистики из второго отчета в файл "report_3.csv"

## Запуск

При запуске введите номер нужного отчета цифрой (1/2/3)
