# Анализ данных о Нобелевских лауреатах

Финальный проект по Python.

## Описание

В проекте обрабатываются и анализируются данные о Нобелевских лауреатах.

Анализируются:
- страны с наибольшим количеством лауреатов и их динамика по десятилетиям;
- возраст получения первой Нобелевской премии;
- гендерное распределение лауреатов;
- частота слов в текстах мотиваций вручения премий.

## Структура проекта

- `laureates_countries_task.ipynb` — ноутбук с анализом, графиками и выводами.
- `laureates.json` — исходные данные.
- `json_dict_processing.py` — функции обработки вложенных словарей.
- `prizes_configs.py` — конфигурация обработки премий.
- `laureates_configs.py` — конфигурации обработки людей и организаций.
- `dataset_helpers.py` — вспомогательные функции.
- `aggregations.py` — функции агрегации данных.
- `stopwords.py` — стоп-слова для анализа мотиваций.

## Запуск

Для работы необходим Python 3, Jupyter Notebook и библиотека `matplotlib`.

1. Установите зависимости: `python3 -m pip install notebook matplotlib`.
2. Откройте `laureates_countries_task.ipynb` в Jupyter Notebook.
3. Убедитесь, что `laureates.json` и все `.py`-модули находятся в той же папке.
4. Выполните все ячейки последовательно от начала до конца.
