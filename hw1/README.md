# Домашнее задание 1

Решения 5 заданий по Python

Код каждого задания находится в своем файле (Задание_1.py - Задание_5.py)

## Требования

- Python 3, дополнительные библиотеки не требуются

## Запуск

Каждый файл запускается независимо и выводит результаты вычислений в терминал

Надо открыть терминал в корневой папке репозитория и выполнить нужную команду

python3 hw1/Задание_1.py
python3 hw1/Задание_2.py
python3 hw1/Задание_3.py
python3 hw1/Задание_4.py
python3 hw1/Задание_5.py
